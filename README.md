# Projeto de Banco de Dados

Projeto acadêmico desenvolvido para a disciplina de Banco de Dados, utilizando Python e MySQL.

## Sobre o projeto

O projeto consiste no desenvolvimento de uma aplicação integrada a um banco de dados, permitindo realizar operações de cadastro, consulta, alteração e gerenciamento de informações.

O objetivo foi aplicar na prática conceitos de programação, modelagem de banco de dados e integração entre uma aplicação Python e um banco de dados MySQL.

## Tecnologias utilizadas

* Python
* MySQL
* SQL

## Funcionalidades

* Cadastro de informações
* Consulta de dados
* Alteração de registros
* Exclusão de registros
* Integração com banco de dados MySQL
